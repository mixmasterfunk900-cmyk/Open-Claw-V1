# V4 Rejection + V5 Lock

Status: **V4 REJECTED — DO NOT SHIP / DO NOT USE AS ACTIVE REVIEW**

Masala reviewed V4 and rejected it.

## Why V4 failed
- Local deterministic stick-figure render quality was bad and not acceptable for the channel.
- It violated the locked finance decision: minimum valid finance video length is 8 minutes; V4 was ~5:46.
- It did not use the required GPT/frontier image model for the actual visual remake.
- It solved character drift with the wrong method instead of using GPT image generation with a consistent stick-figure/cartoon style lock.
- The workflow/QA failed because these requirements should have blocked V4 before user review.

## V5 locked direction
- Use ChatGPT/OpenAI image generation again, not local doodle rendering.
- Style: high-quality stick-figure / simple animated explainer styling, generated by ChatGPT image gen, consistent across all frames.
- Main characters must remain visually consistent throughout via fixed style prompts and reference/lock strategy.
- Minimum valid runtime: 8 minutes or longer. Do not trim below 8 minutes.
- Beat processing must map visuals accurately to what the speaker is saying.
- Subtitles remain: white, thin outline, no box; 30% smaller and 20% lower than V3 unless superseded.
- V5 must not be marked current until proof/QA passes.

## Hard QA additions
- Runtime gate: fail if < 480 seconds.
- Model provenance gate: fail if visual scene assets are not GPT/frontier-generated.
- Local fallback gate: fail if local placeholder/shortcut visuals are used as final.
- User-review proof gate: create a small style+beat proof before full expensive generation.
