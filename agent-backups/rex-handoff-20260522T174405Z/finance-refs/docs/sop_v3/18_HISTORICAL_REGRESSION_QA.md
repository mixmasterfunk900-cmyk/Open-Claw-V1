# 18 — Historical Regression QA

This QA pass exists because prior runs failed in ways the SOP should have caught automatically.

## Rule

Regression QA runs before final render, after render, and before Vibe Zone. If any historical failure appears, final status must be `REGRESSION_QA_FAILED`, not complete.

## Historical failures to check

### Character failures

- Laura changes race/skin tone.
- Laura changes age range.
- Laura changes face/hair identity.
- John changes race/skin tone.
- John changes age range.
- John changes face/hair identity.
- Laura/John swap visual roles.
- Characters become semi-realistic portraits instead of cartoon characters.

### Style failures

- Mixed art styles across scenes.
- Drawn realism / semi-realistic editorial style.
- 3D render, anime, photorealism, painterly realism.
- Scene looks from a different cartoon generation/universe.

### Image generation failures

- Same image loops/repeats/cycles.
- Scene files are copied from a small key-image set.
- Visible 2x2 grid, collage, split panel, contact sheet, or composite in any scene asset.
- Final render shows grid/collage/contact-sheet imagery.
- Missing one full-frame image per beat.
- Beat image does not match script/audio moment.
- Model/provider provenance missing for any generated beat.
- Any beat generated by a lower-tier fallback without Debug Agent report.

### Editing failures

- Static slideshow with no faint zoom/drift.
- No transitions where transition plan requires them.
- Motion/transition metadata exists but final render does not show actual motion.
- Excessive or distracting motion.

### Subtitle failures

- Black box/background/highlight behind subtitles.
- Subtitles too large.
- Subtitles wrap to two or more lines.
- Subtitle text is not white with thin black outline.
- Subtitle timing is off beat.
- Subtitle gaps while voice is active.

### Reporting/tracker failures

- Tracker remains all planned after work starts.
- Every row owned by Director.
- Reporting/Tracker Agent absent.
- Tracker not updated within the last 5 minutes while run is active.
- Google Sheet/Drive/local tracker status is not explicit.

## Pass criteria

Every historical failure class must be checked. A missing check is a fail.
