# Dog Content SOP Checklist

This is the hard gate for Dog Content scripts before Masala generates audio.

## Required pipeline
1. Research for high viral/search potential.
2. Write researched long-form voiceover script.
3. Create source notes.
4. Create SEO title/description.
5. Create visual-plan stub and later expand to 100+ audio-timed beats after WAV.
6. End with a clear CTA/next-video bridge so each video leads into the next.

## Writing formula
Every audio-ready script must include:
- familiar owner-recognition hook in the first lines;
- common/simple assumption people make;
- curiosity turn: the common answer is too small/wrong/incomplete;
- research-backed explanation without overclaiming;
- body-language/context nuance rather than one fixed translation;
- practical owner takeaway;
- emotional payoff;
- next-video CTA that says what the next video will cover.
