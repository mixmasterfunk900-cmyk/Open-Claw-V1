# Vibe Zone Confirmed Template #2 — 50/50 Script-Aware Generated Scenes

Approved by Masala on 2026-05-15.

## Status

**Confirmed Template V2** for experimental/next-gen shorts where the video is driven by voiceover plus generated contextual visuals.

This does **not** replace Confirmed Template #1 as the default short-form template unless Masala explicitly says so. V1 remains preserved. V2 is an approved additional format.

## Core layout

- Vertical 9:16 output.
- Top section: tracked/isolated facecam/camera crop.
- Bottom section: generated contextual images/scenes.
- Captions/subtitles flash at the seam where the facecam and generated image meet.
- Current approved direction is approximately a **50/50-style split** / facecam + visual-scene composition. Exact ratios can be tuned per source, but the intent is: face/camera prominent on top, generated scene prominent below.

## Visual scene rules

- Generated scenes must be relevant to what is being spoken in the script/voiceover at that time.
- Do not use random generic image rotation.
- Read the script/transcript first.
- Plan image beats every ~4–6 seconds.
- Generate/build images for each beat from the actual meaning/context of that section.
- Images do not need to be perfect or literal, but they must clearly connect to the script.
- Avoid simple generic diagram cards with giant literal words baked into the image.
- Prefer detailed, contextual, cinematic scenes generated from the script context.
- Image styling can be tweaked/improved in future iterations; the approved part is the structure/concept/workflow.

## Caption rules

- Captions must be checked carefully.
- Captions should be accurate to the spoken voiceover.
- Caption timing must be verified; previous tests had timing/word issues.
- Captions sit at the split/seam and should be readable without covering the face or key image detail.
- Avoid useless standalone fragments when possible, while preserving transcript accuracy.

## Required workflow

1. Pick the short/voiceover source.
2. Read transcript/script and word timings.
3. Create a beat plan at roughly 4–6 second intervals.
4. For each beat, write a contextual image prompt based on what is being said.
5. Generate/build the scene images.
6. QA images for relevance to the script.
7. Render with facecam/camera section + generated scene section.
8. QA captions for timing/readability.
9. QA the full contact sheet for scene changes, script relevance, and layout consistency.
10. Only then send/review the output.
